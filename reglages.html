Publication

L’aperçu reste dans ce navigateur. Pour publier, le jeton doit pouvoir écrire le contenu du dépôt oreka-metz.github.io. Il reste dans cet onglet seulement, jusqu’à sa fermeture, et il n’est pas enregistré dans le site.

  1. Créer un jeton fin : propriétaire oreka-metz, dépôt oreka-metz.github.io seulement, permission Contents sur Read and write.
  2. Ne cochez pas le droit classique repo : il permet de modifier tout le dépôt, pas seulement les textes et les images.
  3. Collez le jeton, puis publiez. Le site public se met à jour en une minute environ.
