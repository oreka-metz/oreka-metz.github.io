Publication

L’aperçu reste dans ce navigateur. Pour que tout le monde voie les changements, publiez avec un jeton GitHub du compte qui possède le dépôt. Le jeton n’est pas enregistré dans le site : il reste dans ce navigateur.

  1. GitHub → Settings → Developer settings → Personal access tokens.
  2. Jeton classique avec le droit repo, ou jeton fin limité au dépôt oreka-metz.github.io, contenu en lecture et écriture. Les jetons classiques sont sur cette page.
  3. Collez-le ici, puis publiez. Le site public se met à jour en une minute environ.
